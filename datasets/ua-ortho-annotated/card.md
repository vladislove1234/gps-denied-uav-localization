# ua-ortho-annotated — dataset card

> Equipment. Written by hand; `manifest.json` is generated by the first real
> export. **Status: no samples yet.**

## What this is

Hand-drawn 6-class labels (same registry as `ua-village-annotated`) over
test-area satellite images that have no exact georeference. First and only
image: `gonchary-2025-ortho`, the raw 2025 Google Earth frame the
position-correction harness matches against.

| | |
|---|---|
| Sample = | one image → `<slug>/label.png`, class ids 0–5, 2731×2009 at ~0.2 m/px |
| Back to the raw frame | resize NEAREST to `source_shape` (6026×8192); `scale_to_source` ≈ 3.0 |
| Georeference | none (`crs: "pixel"`); `bounds_approx` is the 2025 linear corner fit, for orientation only |

## Known problems

- One image, one area, one season (April 2025). It is the harness's test
  area, so these labels are **evaluation** data for that area, not training
  data to be mixed in without saying so.
- Drawn at 0.2 m/px; details finer than that are lost when mapping back to
  the 6.7 cm/px source.
