# ua-drone-annotated — dataset card

> Equipment. Written by hand; `manifest.json` is generated by the first real
> export. **Status: no samples yet.**

## What this is

Hand-drawn 6-class segmentation labels (same registry as `ua-village-annotated`:
background, building, track, woody, field, water) over the frames of
`drone-2025-easy`, drawn in `tools/annotator/` with no reference seeding.
Kept separate from the satellite labels so the two domains never mix silently.

| | |
|---|---|
| Sample = | one frame → `<frame>/label.png`, class ids 0–5, 1920×1080, in frame pixels |
| Georeference | none. Each `samples.jsonl` record carries `crs: "pixel"` and `position` (timestamp, lat, lon, alt, yaw from the flight log) |
| Export | `python -m tools.annotator export --new` exports both collections; drone records go to this dataset's own `samples.jsonl` |

## Known problems

- Single annotator, no agreement measure.
- One flight (2025-04-05), early spring (dry grass), one area. Not evidence for
  other seasons or terrain.
